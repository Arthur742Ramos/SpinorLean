# Third-party LaTeX template files

The following files are included to prepare an AACA / Editorial Manager LaTeX
source package:

- `birkjour.cls`
- `spmpsci.bst`
- `cite.sty`

They were copied from the `birkjour.zip` package linked from the AACA submission
guidelines page:

```text
https://link.springer.com/journal/6/submission-guidelines
https://media.springer.com/full/springer-instructions-for-authors-assets/zip/1699317_birkjour.zip
```

These files are included for author-submission compatibility with Advances in
Applied Clifford Algebras and Editorial Manager. Do not modify the class file
unless the journal explicitly instructs otherwise.
